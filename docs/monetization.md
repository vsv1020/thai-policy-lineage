# 营收与广告位

## 先说约束:中立性就是护城河

调研报告第四章的结论是,中文世界的泰国政策信息「供给方多为利益相关方」,
**「无带货、可溯源」的中立平台本身就是定位**。所以变现有一条不能碰的线:
任何让读者怀疑「这条政策解读是不是为了卖东西」的做法,都在拆自己的护城河。

落到代码里是三条机械规则(`js/ads.js` 执行,改配置绕不过去):

1. **类别白名单**:只有 `config/ads.json` 的 `allowed_categories` 里的类别会渲染。
   签证中介、代持服务、移民掮客、博彩、未持牌金融不在名单里 —— 配置了也不显示。
2. **位置隔离**:广告只出现在侧栏、政策流卡片之间、详情页右栏、落地页正文之后。
   永远不进政策正文、摘要、检索结果行内。
3. **明确标注 + `rel="sponsored nofollow"`**:每个广告位都带「广告」字样;搜索引擎不把付费链接当推荐。

## 收入结构(按优先级)

| 优先级 | 来源 | 为什么 | 前置条件 |
|---|---|---|---|
| 1 | **企业法规监测订阅** | 调研报告的核心判断:对企业是合规成本不是资讯消费,付费逻辑硬 | 订阅推送(未实现)、按行业打包 |
| 2 | **持牌机构直销赞助** | 律所、会计师事务所、银行的目标客户与本站读者高度重合;按月固定费,不依赖流量 | 本文件下方的广告位,已可用 |
| 3 | **定制报告 / 数据报告** | 已有结构化库与七维分析,边际成本低 | 数据量上来(目前 15 条,远不够) |
| 4 | 程序化广告(AdSense) | 仅作没有直销时的兜底 | 流量;中文垂直小站 RPM 很低,不要指望 |
| 5 | API / 数据授权 | 调研报告:需要 2 年以上语料积累才有壁垒 | 长期 |

**现实判断**:在数据量和流量起来之前,广告收入会很小。广告位的真正用途是
**让第一批持牌机构赞助商有地方放**,并为以后的企业订阅做自有推广(`house` 类别)。
上线初期的重点应该是把采集跑通、把条目数量做到几百条、把 SEO 落地页铺开 —— 这些决定了
后面每一种收入的上限。

## 广告位清单

| 槽位 id | 位置 | 适合 |
|---|---|---|
| `home_sidebar_nav` | 左侧导航栏底部 | 品牌名 + 一行字,窄位 |
| `home_sidebar` | 首页右栏,生效日历下方 | **主力位**,首屏可见 |
| `home_feed_inline` | 首页政策流第 N 张卡片之后(`after_index`) | 原生卡片样式 |
| `detail_side` | 详情页右栏 | 与所看政策领域相关的服务 |
| `landing_bottom` | 每个 SEO 落地页正文与免责声明之后 | 搜索流量入口,长期价值最高 |

## 上一条赞助广告

编辑 `config/ads.json`:

```json
{
  "enabled": true,
  "slots": {
    "home_sidebar": {
      "items": [{
        "sponsor": "某某律师事务所",
        "category": "law_firm",
        "title": "外资公司设立与 BOI 申请",
        "text": "持牌律所 · 中文服务",
        "href": "https://example.com/?utm_source=policy-lineage&utm_medium=sponsor",
        "start": "2026-10-01",
        "end": "2026-12-31"
      }]
    }
  }
}
```

然后 `cd backend && python3 -m app.export`,提交。同一槽位多条时随机轮播;
`start`/`end` 之外自动不显示,到期不用手动下架。链接务必带 UTM,给赞助商看转化是续约的依据。

**签约前核对持牌**:律所查泰国律师协会(Lawyers Council of Thailand)登记,
会计师事务所查 TFAC,银行与保险查 BOT / OIC。白名单只能管类别,管不了资质真假 —— 这一步必须人工做。

## 启用 AdSense(兜底)

在 `config/ads.json` 的 `adsense.client` 填 `ca-pub-XXXXXXXX`,各槽位填广告单元 id。
导出时会自动生成根目录的 `ads.txt`。直销广告优先,槽位没有有效直销时才出 AdSense。
注意 AdSense 审核要求站点有足够原创内容 —— 15 条的库大概率过不了,等条目数上来再申请。
