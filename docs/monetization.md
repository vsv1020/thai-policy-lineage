# 营收:免费站 + 打赏 + 广告

## 模式

全站免费、无注册、无付费墙。收入两条腿:

| 来源 | 适合谁付 | 现状 |
|---|---|---|
| **读者打赏** | 被某条政策帮到的个人读者 | 已实现:PromptPay 动态金额二维码 / 微信赞赏码 / 支付宝 / Buy Me a Coffee |
| **广告** | 持牌律所、会计师事务所、银行等直销赞助;没有直销时 AdSense 兜底 | 已实现:5 个广告位、类别白名单、到期自动下架 |

两者都是**流量的函数**。上线初期的真正任务不是调广告位,而是把条目数从 15 条做到几百条、
把 SEO 落地页铺开 —— 这决定了后面所有收入的上限。

## 约束:中立性就是护城河

调研报告的结论:中文世界的泰国政策信息「供给方多为利益相关方」,**「无带货、可溯源」本身就是定位**。
所以下面三条写进了代码(`js/ads.js`),改配置绕不过去:

1. **类别白名单**:只渲染 `allowed_categories` 里的类别。签证中介、代持服务、移民掮客、博彩、
   未持牌金融不在名单里 —— 配置了也不显示;`tools/validate.py` 还会拒绝把它们加进白名单。
2. **位置隔离**:广告只在侧栏、卡片之间、详情页右栏、落地页正文之后。不进政策正文、摘要、检索结果行内。
3. **明确标注 + `rel="sponsored nofollow"`**,每条必须写明 `sponsor`(校验器强制)。

打赏同理:**打赏不影响任何内容的取舍与排序**,这句话写在打赏弹窗和隐私政策里。

## 打赏

### 开启

编辑 `config/support.json`,填至少一个渠道,把 `enabled` 改为 `true`,然后
`python3 tools/validate.py && cd backend && python3 -m app.export`,提交。
没填的渠道自动不显示;全部为空时打赏入口整体隐藏。

入口:顶栏「☕ 打赏支持」按钮、详情页正文后、每个 SEO 落地页正文后。

### 各渠道注意事项

- **PromptPay(泰国读者主力)**:页面按所选金额(默认 ฿30/100/300,可改 `amounts_thb`)实时生成二维码,
  泰国任意银行 App 可扫。**上线前用自己的银行 App 实扫一次 ฿1**,这一步没有替代。
  - ⚠️ **不要用个人手机号**:号码会被编码进二维码,任何人解码都能看到;扫码付款时银行 App
    还会显示收款人**真实姓名**。用公司税号(13 位)或电子钱包号(15 位)。校验器对手机号会给出提醒。
- **微信**:用「**赞赏码**」,不要用个人收款码 —— 个人收款码按平台规则不能用于经营性收款,可能被限额或风控。
- **支付宝**:同理,优先用平台允许的打赏/收款方式。
- **Buy Me a Coffee / Ko-fi**:海外读者与信用卡用户;平台抽成约 5%,但省去跨境收款的麻烦。
- 收款码图片放在 `assets/support/` 下 —— 只有这个目录对外公开,放在别处不会显示(校验器会报错)。

### 合规提醒

打赏是收入,要按收款主体所在地申报。调研报告第七章还提到:**人在泰国运营网站本身可能构成
泰国法下的「工作」,需要工作许可**(DTV 签证只覆盖为境外雇主远程工作)。用什么主体收款、
在哪里申报,开打赏前请咨询泰国持牌会计师或律师。

## 广告

### 广告位

| 槽位 id | 位置 | 适合 |
|---|---|---|
| `home_sidebar_nav` | 左侧导航栏底部 | 品牌名 + 一行字 |
| `home_sidebar` | 首页右栏,生效日历下方 | **主力位**,首屏可见 |
| `home_feed_inline` | 首页政策流第 N 张卡片之后 | 原生卡片样式 |
| `detail_side` | 详情页右栏 | 与所看政策相关的服务 |
| `landing_bottom` | 每个 SEO 落地页正文之后 | 搜索流量入口,**长期价值最高** |

### 直销赞助(优先)

编辑 `config/ads.json`(字段示例见文件里的 `_item_example`),`enabled: true`,导出、提交。
同一槽位多条随机轮播,`start`/`end` 之外自动不显示。链接带 UTM,续约时给赞助商看转化。

签约前**人工核对持牌**:律所查泰国律师协会(Lawyers Council of Thailand),会计师事务所查 TFAC,
银行与保险查 BOT / OIC。白名单只能管类别,管不了资质真假。

定价:早期流量低,按 CPM 卖不出价,建议**按槽位按月固定费**,首批给试用期,换取案例与续约。

### AdSense(兜底)

1. `config/ads.json` 的 `adsense.client` 填 `ca-pub-XXXXXXXX`,各槽位填广告单元 id。导出时自动生成 `ads.txt`。
2. **不要开「自动广告」(Auto ads)**:它会把广告插进正文,直接违反上面的位置隔离原则。只用手动广告单元。
3. 审核需要**足够的原创内容** —— 15 条大概率过不了,等条目数上来(建议几百条、落地页被收录后)再申请。
4. 已有隐私政策页(`privacy.html`),说明了广告 Cookie 与退出方式,这是 AdSense 的硬性要求。
5. 有欧洲经济区/英国访客时,在 AdSense 后台启用 Google 自带的「隐私权和消息」同意弹窗(免费,Google 认证的 CMP)。

## 要看的数字

在决定任何变现调整之前,先要有流量数据。建议接一个**无 Cookie 的统计**
(Cloudflare Web Analytics 免费、无需同意弹窗),以及 Google Search Console 看落地页的收录与点击。
没有这两样数据,调广告位和打赏文案都是盲调。
