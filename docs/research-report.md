# 泰国政策信息聚合平台 · 调研报告与最终形态设计

**面向在泰华人的泰国政府政策中文信息平台**
调研日期:2026 年 8 月 10 日 · 项目:Info For Thai

---

## 一、执行摘要

本次调研围绕四个问题展开:数据从哪来、市场上有谁、技术怎么做、法律和钱怎么算。结论如下。

**这个项目成立,而且空白程度超出预期。** 泰国政策信息在中文世界的供给,目前全部停留在"新闻编译"层面:泰国头条新闻、泰国网等头部中文媒体做的是社会新闻流,政策内容碎片化、无原文溯源、不可检索;大量"政策解读"实际由签证中介和留学中介生产,服务于成交而非准确性,中国驻泰使馆甚至专门发文警告过这类信息骗局。英文世界有律所的法规更新(Tilleke、Lexology)但没有中文层;泰国本土连英文的全域法规监测创业公司都不存在——法规监测在泰国是全语言空白。**"自动监测泰国官方源 + 可溯源中文结构化 + 分类与趋势分析"这个组合,当前市场上是零竞争的空位。**

**数据可得性比预想的好得多。** 泰国皇家公报(一切法律法规的唯一法定生效渠道)自 2023 年起完全在线化,官方在开放数据平台 data.go.th 上提供逐月 JSON 索引和 Web Service;内阁决议库收录 10.9 万条历史决议且提供逐年 JSON——这意味着最核心的两个数据源不需要硬爬,官方接口直取,而 10.9 万条决议存量直接支撑"趋势分析"功能的冷启动。已有开源项目(narze/ratchagitja.md)跑通了"公报索引 → PDF 下载 → 文本抽取"全流程,可直接参考。

**法律基础坚实,但有三条不可触碰的红线。** 泰国《版权法》B.E. 2537 第 7 条明文规定宪法、法律、部令、公告、判决及官方翻译不受版权保护——抓取、转载、翻译官方文本无需任何授权;《计算机犯罪法》只打击绕过安全措施的访问和干扰行为,礼貌抓取公开页面不构成犯罪。三条红线:王室相关内容零加工零评论(刑法 112 条按帖累加刑责)、名单类公告不做人名数据库(PDPA 敏感数据)、在泰落地不用泰籍代持结构(FBA nominee 刑责,2024 年起正针对中资集中排查)。

**技术成本低到可以一人启动。** LLM 不是成本瓶颈:按每天 200 份文件的处理量,用 Gemini Flash 级模型走 Batch API,月成本仅 $10-40;MVP 全套(抓取 + OCR + 翻译 + 网站)月成本约 $35-150,历史回填 5-10 万份文件一次性 $300-2,000(大头是泰文 OCR,可用泰国本土开源的 Typhoon OCR 压到更低)。真正的壁垒不在钱,在于抓取覆盖度、翻译质检流程和跨源政策关联(把同一政策的草案、内阁决议、公报刊登、生效串成时间线)。

**市场"小而硬",商业模式应以 B 端为核心。** 可服务人群约 25-35 万长居中国公民(长居、留学、投资、经商,且结构上"游客缩水、经商增长"对本项目有利);中国连续多年是泰国 BOI"项目数第一"的投资来源国(2024 年 810 个、2025 年 982 个项目),大量不熟悉泰文的中小企业主构成付费主力画像。推荐路径:C 端免费内容 + SEO 建信任做获客漏斗 → 签证/注册导流做早期现金流 → 企业法规监测订阅(2,000-10,000 元/年/席位)做核心收入,100 家企业客户即可养活项目。

**最终形态一句话:为泰国做一个民间中文版的 EUR-Lex + GovTrack** ——下层是自动化的官方源监测基础设施,中层是可溯源、可检索、场景化分类的中文政策库,上层是订阅预警与趋势情报产品。详见第五章。

## 二、市场与用户

### 2.1 目标人群规模

| 群体 | 数据 | 来源年份 |
|---|---|---|
| 常住中国公民总量 | 约 30 万人(估算) | 2026 |
| 中国留学生 | 24,711 人,第一大留学生来源国 | 2025(泰国高教部) |
| Privilege(原 Elite)长期签证 | 会员近 4 万,中国为第一大申请国籍 | 2024 |
| 外国公寓买家 | 中国人为最大买家(2023 上半年 3,448 套) | 2023(REIC) |
| BOI 中资投资项目 | 2024 年 810 个、2025 年 982 个、2026 上半年 321 个,连续多年项目数全国第一 | BOI 官方 |

核心可服务人群约 25-35 万人。值得注意的结构变化:中国游客 2025 年同比暴跌约 30% 恢复缓慢,但长居、留学、投资、经商人群持续增长——政策信息的刚需恰恰集中在后者。每年约一千个中资 BOI 项目意味着每年新增约一千个"不熟悉泰文但必须跟住泰国法规"的企业决策者。

### 2.2 已被验证的痛点

痛点不是推测,有可观察的证据链。其一,官方信息只有泰文且极度分散:法律在皇家公报、签证在移民局、税在税务厅、投资在 BOI,没有任何中文一站式入口,泰国政府自己只在 BOI 提供中文。其二,信息真空已被产业化利用:中国驻泰使馆 2026 年 7 月专门发文警告"保关"骗局,提醒公民勿信社交媒体未经证实的信息——中介靠信息不对称牟利已成产业。其三,政策突变引发集体恐慌:2024 年底泰国收紧入境审查时,中文网络出现大面积恐慌式传播,需要多方辟谣;DTV 签证的网络攻略版本混乱、材料要求说法不一。其四,高质量内容语言错配:Forvis Mazars、Tilleke 等专业机构的法规更新质量很高,但全是英文;中文内容要么浅、要么带货。

## 三、数据源盘点(调研核心发现)

### 3.1 两个"官方接口级"核心源——项目基石

**皇家公报 Royal Gazette(ratchakitcha.soc.go.th)**:泰国一切法律法规的唯一法定生效发布渠道,签证新政、土地条例、税收法令、最低工资公告最终都落在这里。2023 年起仅在线出版,数字化程度远超多数东南亚国家:可按关键词/类别/卷期检索;分四个系列(ก 法律法规、ข 皇家任命、ค 商业登记、ง 一般公告),政策抓取核心是 ก 类和 ง 类特别号;近年 PDF 有文本层可直接抽取,无需 OCR(早期年份为扫描件);历史 PDF 有可预测的 URL 规律。最关键的是:**内阁秘书处在 data.go.th 发布了官方逐月 JSON 索引(dataset_02_04,含标题/卷/期/类别/日期/PDF 链接)并附 Web Service 使用指南**,官方站还提供 Excel 导出。开源项目 ratchagitja.md 已用"Excel 索引 → CSV → 下载 PDF → 抽取为 Markdown"跑通全流程并持续维护。

**内阁决议库(resolution.soc.go.th)**:收录 109,279 条内阁决议,可按日期、主办部委、关键词检索,列表为服务器端渲染 HTML,对抓取友好,另有 data.go.th 逐年 JSON(dataset_02_03)。内阁决议是泰国政策的"上游"——签证放宽、税收减免、外资措施通常先以内阁决议出现,数周至数月后才见公报。**这是做政策趋势分析和抢首发的最有价值数据源,10.9 万条存量直接支撑趋势功能冷启动。**

### 3.2 MVP 优先接入清单(按信息价值/抓取难度比排序)

| 序 | 信息源 | 覆盖领域 | 难度 | 说明 |
|---|---|---|---|---|
| 1 | 皇家公报官方 JSON + PDF 抽取 | 全领域法定底座 | 低 | 官方月度 JSON 索引,PDF 有文本层 |
| 2 | 内阁决议库 + 年度 JSON | 政策上游、趋势存量 | 低-中 | 比公报提前数周,109k 存量 |
| 3 | thaigov.go.th 新闻中心 | 每周内阁会议纪要(泰/英) | 中 | JS 渲染需 headless,量小 |
| 4 | 税务厅 rd.go.th 英文站 | 税务 | 低 | 静态 HTML,英译法规齐全 |
| 5 | 移民局 + MFA 签证专栏 + thaievisa | 签证/居留(用户价值第一) | 中 | WordPress 架构可探 RSS,需泰国 IP |
| 6 | BOI 公告页 | 投资优惠 | 低 | 官方英文 PDF,低频 |
| 7 | 劳工部 mol.go.th | 劳工/最低工资 | 低 | WordPress,有官方英译 |
| 8 | NNT 英文通稿 / GNews 聚合 | 教育/卫生/交通兜底 | 中 | 覆盖未直接接入的部委 |

二期再接:Krisdika 法律汇编库(现行有效法律全文,做"存量"层)、law.go.th(法律草案公开听证——能看到征求意见阶段的草案,对趋势分析极有价值)、泰国央行 BOT(有成熟的公开 API)、证监会 SEC、海关厅、土地厅。

### 3.3 抓取的现实注意点

泰国政府网站普遍存在 SSL 证书配置问题和对海外 IP/非浏览器 UA 的 WAF 拦截(公报主站、Krisdika、移民局对海外抓取返回 403),生产环境建议泰国本地 IP + 浏览器指纹 + 容忍证书错误;公文使用佛历纪年(公历 + 543)需统一换算;移民局、土地厅公告中扫描盖章件占比较高,需备 OCR。辅助资源:PyThaiNLP 已把 Krisdika 全库做成开放语料(thailaw-v1.0);中国商务部"全球法规网"泰国板块有中文译文库,可作翻译术语基准;Tilleke/Lexology 等律所更新流可作"重要性信号"(律所写了 = 值得做深度中文解读)。

## 四、竞品格局与市场空白

### 4.1 三层竞品扫描

**第一层:中文渠道——有流量,没结构。** 泰国头条新闻(全网粉丝 300 万+,日阅读量 300 万+)、泰国网(老牌门户 + 论坛 + 导流)、@曼谷杂志、VISION THAI(月均 300 万 PV)构成头部;下面是庞大的微信公众号中介生态和小红书攻略号。共同短板:政策内容以推文形态随时间线沉没,无主题库、无检索、无原文链接、无版本追踪;同一政策多个矛盾版本互相转抄;大量内容由利益相关方(中介)生产。没有任何一家做公报级原文追踪。

**第二层:英文/泰国本地——有专业,没中文。** 法条翻译库(Thailand Law Online、samuiforsale、Siam Legal Library)是静态存量翻译,无变更监测,商业模式全是"内容引流 → 法律服务";律所 Legal Update(Tilleke 可免费订阅、Lexology 是英文世界泰国政策订阅的事实标准)专业但纯英文、面向法务人群。**泰国本土 regtech 只有 PDPA 单法合规工具(t-reg、iComply),不存在全域法规监测公司——连英文层面都靠律所人肉盯公报。**值得注意:Baker McKenzie 曼谷设有日本客户专门站,证明"语言专属服务"在泰国被验证过,但没有对等的中文版。

**第三层:国际对标——每个功能模块都有成熟做法可抄。**

| 功能 | 对标产品 | 可借鉴机制 |
|---|---|---|
| 永久唯一 ID + 原文溯源 | EUR-Lex | CELEX/ELI 标识符体系 |
| 三层内容架构 | EUR-Lex | 原文层 → 现行合并版 → 白话摘要层 |
| 场景化导航 | 韩国 Easy Law | 法条按生活场景重组 + 12 种外语 + 卡片新闻 |
| 政策生命周期时间线 | GovTrack / EUR-Lex Law Tracker | 法案状态追踪(提案→通过→生效) |
| 任意切片订阅警报 | GovTrack / Lexology | 按主题/机关/关键词的邮件推送 |
| AI 摘要 + 可验证引用 | Regology(免费 Reggi 引流)/ LawNet | AI 回答强制带原文引用;AI 摘要含在基础订阅 |
| AI 初筛 + 人工复核 | Compliance.ai | 专家在环(expert-in-the-loop)质检 |
| 翻译免责体系 | 日本 Japanese Law Translation | 双语术语词典 + "译文仅供参考、原文为准" |
| 轻成本免费运营 | GovTrack | 一人创立,抓官方数据,广告 + 众筹 |
| 政策情报付费天花板 | FiscalNote(年费中位数 $24k) | 议题仪表盘、通过概率预测、分析师服务层 |

### 4.2 市场空白(结论)

"泰文官方原文 → 可信中文"这条管道完全没人做;变更监测在泰国是全语言空白;结构化能力(分类库、时间线、现行版本、主题订阅、趋势)在中文渠道全部缺失;供给方多为利益相关方,"无带货、可溯源"的中立平台本身就是定位;在泰中资企业目前只能订阅英文源,中文 B 端法规情报订阅是空白价位段。

## 五、产品最终形态设计

### 5.1 定位

**"泰国政策的中文数据库与预警系统"** ——不是又一个新闻号。对用户的三句话承诺:官方源自动监测,重要政策 24-48 小时内出中文;每一条都附泰文原文链接、公报编号、生效日期,可溯源可核实;零带货,不是中介。

### 5.2 三层产品架构

**下层·数据基础设施(护城河):** 自动监测 8+ 官方源;原件永久归档(按 hash 去重);每份文件一个永久唯一 ID(参照 CELEX);结构化字段抽取(发文机关、政策类型、主题标签、生效日期、适用对象);跨源关联——把同一政策的草案听证、内阁决议、公报刊登、生效串成一条链,这是全项目技术含金量最高、最能形成壁垒的一环。

**中层·中文政策库(C 端免费,信任与流量):**

- **今日政策流**:按时间线呈现最新监测结果,每条卡片 = 中文标题 + AI 摘要 + 领域标签 + 发文机关 + 生效日期 + 原文链接 + 公报编号,重要政策标注"已人工复核"。
- **场景化分类导航**(抄韩国 Easy Law):签证居留 / 公司投资 / 税务 / 房产土地 / 劳工用工 / 教育 / 医疗 / 交通出行 / 金融外汇 / 海关贸易。每个场景下有"政策库 + 现行规则速览 + 常见问题"。
- **政策详情页**:中文全译或摘要 + 关键字段卡(生效日期、适用对象、主管部门、罚则)+ 生命周期时间线 + 历史版本 + 相关政策 + 泰文原文对照 + 免责声明(非官方翻译,以泰文原文为准)。
- **检索**:中文搜译文、泰文搜原文的混合检索;按领域 × 机关 × 类型 × 日期 × 生效状态的分面过滤。
- **生效日历**:未来 90 天即将生效/截止的政策倒计时(如报税截止、新规生效日)。

**上层·趋势与情报(差异化 + B 端付费):**

- **趋势看板(免费部分做传播)**:同类政策发文量时间序列(如"签证类政策"按月堆叠图,可钻取到文档列表);政策风向标——LLM 对每条政策标注"收紧/放宽/中性",聚合成各领域风向指数(如"签证政策近 12 月收放趋势");部委活跃度热力图;上升话题榜(关键词热度环比)。
- **订阅预警(个人免费、企业付费)**:按主题/机关/关键词订阅,邮件 + 微信服务号 + LINE 推送;企业版按行业打包(EV/制造、跨境电商、餐饮零售等),含影响评估简报。
- **数据产品**:"泰国签证政策十年收放图谱"式数据报告(传播爆点 + 机构定制);中期开放 API。

### 5.3 页面结构(信息架构)

```
首页          今日政策流 · 本周焦点 · 风向指数摘要 · 生效日历
├─ 政策库     分面检索(领域/机关/类型/日期/状态)
│   └─ 政策详情   摘要 · 字段卡 · 时间线 · 版本 · 原文对照
├─ 场景导航   签证 · 公司 · 税务 · 房产 · 劳工 · 教育 · 医疗 · 交通…
├─ 趋势       发文量时序 · 风向指数 · 部委热力图 · 上升话题
├─ 订阅       个人订阅(免费) · 企业监测(付费)
└─ 关于       数据来源与方法 · 免责声明 · 更正记录
```

### 5.4 趋势分析的具体形态(用户核心需求详解)

趋势分析建立在结构化字段之上,本质是"夜间定时 SQL 聚合 → 汇总表 → 图表",MVP 不需要专门分析引擎。四种核心视图:其一,**主题时间序列**——按月统计各领域发文量的堆叠面积图,回答"最近土地政策是不是变密了";其二,**政策生命周期时间线**——单个政策从草案听证(law.go.th)→ 内阁决议 → 公报刊登 → 生效的垂直时间轴,数据模型照抄 OpenStates 的 bill-action 结构;其三,**风向指数**——LLM 标注每条政策的方向性(收紧/放宽),聚合出领域级指数曲线,这是全市场独有、传播性最强的功能;其四,**部委活跃度对比**——机关 × 月份热力图。跨源关联靠文件编号 + 标题相似度 + LLM 实体对齐。

## 六、技术架构与成本

### 6.1 数据管道(MVP 版)

```
[源清单] → Scrapy 定时抓取 / changedetection.io 变更监测(长尾页面)
  → 原始 HTML/PDF 落对象存储 R2(hash 去重,永久归档)
  → 文本抽取(PyMuPDF)→ 泰文质检(PyThaiNLP 词典命中率)
      → 不合格转 OCR(Typhoon OCR,泰国本土开源,政府文档评测超 GPT-4o)
  → LLM Batch 一次调用完成:泰译中 + 摘要 + 分类标签 + 结构化字段(JSON Schema)
      → Pydantic 校验 + 日期/金额正则复核 → 失败重试
  → PostgreSQL(真源,含 pgvector)→ 同步 Meilisearch(中泰双索引)
  → Next.js(ISR)站点 + ECharts 趋势图 + 邮件/微信推送
```

关键选型理由:Scrapy 是政府公报抓取的验证过的模式(巴西 querido-diario 用它管理数千个爬虫);changedetection.io 让"值得盯但不值得写爬虫"的长尾页面维护成本趋近于零;Typhoon OCR(SCB10X 出品,Apache-2.0)专为泰文文档设计,在泰国政府表格类文档上超过 GPT-4o,有免费 API;翻译摘要用 Gemini Flash 级模型(泰语能力已很强,Gemini 2.5 Pro 泰国高考达 91.5%)+ Batch API 五折;分类用受控标签集避免标签漂移;搜索用 Meilisearch(原生支持泰文和中文分词,运维接近零)。

### 6.2 成本估算

| 阶段 | 月成本 | 说明 |
|---|---|---|
| MVP(200 份/天) | **$35-150/月** | VPS×2 + R2 存储 + OCR + LLM Batch + 域名 CDN |
| 其中 LLM | $10-40/月 | Gemini Flash 级 Batch;LLM 不是成本瓶颈 |
| 历史回填 5-10 万份 | 一次性 $300-2,000 | 大头是 OCR(约 40 万页);LLM 仅 $110-1,250 |
| 成熟版(500-1000 份/天) | $900-2,300/月 | GPU 节点(自托管 OCR/embedding)+ OpenSearch 集群 + 分级 LLM |

成熟版升级路径:Prefect 编排 + Playwright 池、OpenSearch 混合检索(BM25 + BGE-M3 向量 + RRF)、分级 LLM(Flash 级全量 + Sonnet/Pro 级精翻重点法规与版本对比)、人工复核后台、LINE 官方账号推送(在泰触达必备)、B2B API。

### 6.3 质量护栏(产品能否被认真对待的关键)

法律文本的 OCR 与翻译错误代价高。四层防御:生效日期、金额、刑罚类字段做程序化二次校验(正则比对原文数字);重大政策(签证/税/土地)双人或 AI + 人工复核,页面标注复核状态;每篇挂原文链接 + 公报编号构成可溯源证据链;显著的更正机制与修订时间戳(同时是对抗《计算机犯罪法》"虚假信息"条款的主观要件抗辩材料)。

## 七、合规与风险

### 7.1 法律基础(利好)

**版权:** 《版权法》B.E. 2537 第 7 条明文规定不视为版权作品:宪法与法律;部、厅及政府机构的规章、公告、命令、解释函;司法判决与官方报告;以及政府自制的上述翻译与汇编。抓取、转载、翻译官方文本无需授权;你的中文译文反而构成自己可主张权利的资产。边界:政府网站上的解读文章、信息图、照片不在豁免清单内;泰国媒体报道受版权保护,只能合理引用。

**爬虫:** 《计算机犯罪法》第 5/7 条的构成要件是"绕过安全措施 + 未经授权",抓取无需登录的公开政府网页不满足要件;泰国无专门禁爬法,也无针对抓取公开信息的刑事判例。需防范第 10 条(干扰计算机系统):限速(单站 ≤1 请求/秒)、错峰、遵守 robots.txt、可识别 UA、优先走开放数据接口。data.go.th 的 DGA 开放政府许可明确允许复制、传播、再利用。

**个人数据:** PDPA 有两条通道——第 4(3) 条大众媒体豁免(部长级公开确认适用于媒体报道)+ 第 24(5) 条合法利益。

### 7.2 三条红线(硬性编辑规则)

1. **王室零加工**:刑法 112 条(冒犯君主罪)3-15 年/帖、按帖累加,任何公民可报案。所有法律以国王名义颁布,中性转载官方原文是安全的、泰国媒体每天在做;风险在"加工"。规则:王室内容只登官方文本 + 规范译名,零评论零演绎零标题党(赞美性内容同样有风险),相关文章关闭评论。
2. **名单类公告不做人名库**:公报中的归化名单、破产公告只做摘要性报道,不建可检索人名索引;破产/刑事信息属 PDPA 准敏感数据。
3. **不碰泰籍代持**:FBA 下 nominee 结构对双方都是最高 3 年监禁,2024 年起泰国正针对中资背景公司集中排查。

### 7.3 主体架构建议

分三阶段:起步期用海外主体(香港/新加坡公司)+ 境外服务器 + 境外收款,不在泰设实体,合规成本最低;变现落地期申请 **BOI 数字业务类促进**(软件/数字服务允许 100% 外资、豁免 FBA 限制、配发工作许可)——中资科技公司标准路径;公司经营范围表述刻意避开"新闻/报社"字样(FBA List One 明列报纸业务禁止外资,纯网站属灰色地带,定性为"数字信息服务"更稳)。注意:人在泰国运营即构成泰国法下的"工作"需工作许可,DTV 签证只覆盖为境外雇主远程工作;若日后增加"对接签证代办/律所"的撮合功能,可能触发《数字平台服务法令》向 ETDA 备案的义务。纯线上资讯网站目前不需要媒体牌照。

### 7.4 风险清单

| 风险 | 等级 | 缓解 |
|---|---|---|
| 政治敏感(112 条 + CCA 14(3)) | 高危低频 | 硬编辑规则 + 敏感词清单 + 发布前卡点 + 敏感文关评论 |
| 翻译错误致用户损失 | 中危中频 | 三重免责声明 + 原文溯源 + 重大政策人工复核 + 更正机制 |
| 政府网站改版/反爬中断 | 高频低危 | 多源冗余 + 抓取解析解耦 + 零更新告警 + 官方 FB 页兜底 |
| 竞争(头部媒体增设政策栏目) | 中危 | 往 B 端纵深走;结构化语料库与客户关系是新闻号无法快速复制的 |
| 单人维护可持续性 | 高危 | 管线极致自动化(人工压到 2-3 小时/天);做"库"不做"日更新闻",存量内容持续产生 SEO 流量;尽早雇 1 名泰籍双语编辑 |

## 八、商业模式

### 8.1 变现路径评估

核心判断:**B 端法规监测订阅是主模式**,付费逻辑硬(对企业是合规成本,不是资讯消费)。每年约 1,000 个中资 BOI 项目 + 数百家新设公司构成客户池,按行业打包(EV/制造、电子、跨境电商、餐饮)推送法规预警 + 影响简报,定价 2,000-10,000 元/年/席位,100 家客户即达温饱线,500 家即是一门好生意。C 端个人订阅谨慎(中文用户资讯付费意愿低),仅"重大变化深度解读"可做百元级年费会员。导流分成(签证/注册/房产,只与持牌机构合作、明示广告标识)做早期现金流——泰国网已验证此模式,但必须与黑中介切割,这是品牌生命线。定制报告(5 千-5 万元/单)承接订阅客户深度需求。API/数据授权是中期选项,需 2 年以上语料积累后才有壁垒。律所内容合作(专业审稿换中文获客)既是质控也是竞争防御。

### 8.2 分阶段策略

**阶段一(0-12 月,验证):** 全免费建信任 + 导流分成第一笔现金流 + 1-2 家律所审稿合作。目标:触达 1-2 万在泰华人,跑通"公报当日中文"流水线。
**阶段二(12-24 月,变现):** 上线企业监测订阅(先做 2 个行业包),深度解读进会员。目标:50-150 个企业席位。
**阶段三(24 月+,平台):** API 数据服务、数据库授权、复用管线扩展越南/印尼("东南亚政策监测")。

### 8.3 冷启动获客

最大红利是 **Google 中文长尾 SEO**:在泰华人普遍用 Google,现有中文媒体全做社交分发几乎不做结构化 SEO,而每篇政策译文天然是一个长尾着陆页("泰国 DTV 签证 条件""泰国公司注册 外资比例""泰国养老签证 存款")。配合:微信公众号做"预警"心智(重大政策第一时间 + 使馆信源交叉核实),服务号模板消息即企业订阅交付通道;小红书做场景化选题引流;在免签调整、税改等政策突变节点做辟谣快评(被验证过的涨粉场景)。内容格式本身就是差异化:每篇"泰文原文截图 + 公报编号 + 生效日期",与谣言号形成可视化区隔。
